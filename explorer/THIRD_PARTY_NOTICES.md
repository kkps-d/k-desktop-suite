# Third-party notices

Original Explorer code and its simple vector icons are MIT licensed; see the
root `LICENSE`. Third-party components retain their respective licenses.

- `src/main/assets/licenses/Runtime-NOTICES.txt` contains the AndroidX,
  Kotlin, and coroutine dependency inventory, Apache 2.0 text, and upstream
  notices, based on the suite's existing runtime inventory.
- `core/ui/src/main/assets/licenses/` supplies the suite MIT text and the Noto
  font copyright notices and SIL Open Font License 1.1 texts packaged by the
  shared UI module.

Explorer is currently a UI validation shell; no About or license viewer is
implemented. Notices are bundled in the APK assets. Update the inventory when
release dependencies change; test and build dependencies are excluded.

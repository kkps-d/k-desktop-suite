# Screenshot inventory

Captured 7 November 2026 from current local debug apps. Compact views are resized Small Desktop windows, not physical phones. Crop values are `[x, y, width, height]` in source pixels. The two `floating-windows-desktop` additions retain the entire 1366 × 768 frame with **no cropping**. See [capture conditions](README.md).

Each entry links to its untouched device PNG and JPEG web copy. Menus, edit handles, and selected-shape labels are intentional native UI. The supplemental full-desktop captures also retain the native desktop pointer. Scrollable notes and 100% canvas navigation can extend beyond their viewport.
